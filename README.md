### Projetos

* **[SOIL](https://github.com/sagihtt/soil):** Plataforma B2B para especificação técnica veicular e orçamentos multicritério. Desenvolvida em TypeScript estrito, Clean Architecture, DDD e suíte TDD com 40 testes automatizados.
* **[Engine](https://github.com/sagihtt/engine):** Sistema de gestão de jornada e controle operacional da equipe do Projeto Engine (IESB Oeste), operando em produção com Nginx, Express, sessões seguras e web terminal SSH2.
* **[Interface-Design](https://github.com/sagihtt/Interface-Design):** Projeto final da disciplina de Projeto de Interface (IESB ADS), apresentando arquitetura frontend responsiva e hospedagem ativa em `lab-1.engine.lat`.
* **[Lotofácil](https://github.com/sagihtt/lotofacil):** Aplicação web e mobile-first em React Native (Expo Web) e TypeScript para geração combinatória e filtragem probabilística de apostas, hospedada em `lotofacil.engine.lat`.
* **[Krono](https://github.com/sagihtt/krono):** Aplicativo multiplataforma (Android, iOS, Web) em React Native (Expo SDK 58 + Expo Router) para gestão de ponto e frequência, integrando operação offline-first e API RESTful Node.js.
